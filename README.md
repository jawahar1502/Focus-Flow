# 🚀 FocusFlow — JARVIS Edition

### Your Day. Your Mission. Execute.

FocusFlow is a futuristic, Iron Man JARVIS-inspired personal productivity website designed to help users organize their daily tasks, manage study schedules, track habits, and improve productivity through a sleek interface with vibrant gradients and 3D animations.

## ✨ Features

- ✅ **To-Do List** — Create, manage, prioritize, and track tasks.
- ⏰ **Smart Reminders** — Schedule reminders and receive browser notifications where supported.
- 🎯 **Pomodoro Timer** — Improve focus with customizable study and break sessions.
- 📅 **Study Timetable** — Organize weekly study schedules.
- 🔥 **Habit Tracker** — Build consistent habits and monitor streaks.
- 📊 **Productivity Analytics** — Visualize task completion and study progress.
- 🏆 **Goals & Milestones** — Set targets and track achievements.
- 📝 **Quick Notes** — Capture ideas and organize notes.
- 📖 **Daily Journal** — Record daily reflections and accomplishments.
- 💰 **Expense Tracker** — Monitor income, expenses, and budgets.
- 🔐 **Login & Signup** — Frontend demonstration authentication.
- 🎨 **JARVIS-Inspired UI** — Dark interface, vibrant gradients, and futuristic visual effects.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage
- CSS 3D Transforms and Animations
- Browser Notifications API

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- VS Code Live Server extension (recommended)

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/jawahar1502/FocusFlow.git
   ```

2. Open the project folder:

   ```bash
   cd FocusFlow
   ```

3. Open the folder in Visual Studio Code.

4. Run `index.html` using the Live Server extension.

5. Create a demo account and explore the available features.

> If your project uses a different entry file or folder structure, adjust these instructions accordingly.

## 💾 Data Storage

FocusFlow uses browser LocalStorage to save supported application data locally.

- Data generally remains available after refreshing the page in the same browser.
- Data is not automatically synchronized across devices.
- Clearing browser storage may permanently delete saved data.

## 🔔 Reminder Limitations

Browser notifications require user permission. Alarm behavior depends on browser and operating-system capabilities. Reminders cannot be guaranteed when the browser is closed or the device is asleep.

## 🔐 Authentication Disclaimer

The login and signup functionality is intended for demonstration purposes. This frontend-only project does not provide production-grade authentication or secure storage for real user credentials. Do not enter sensitive personal information.

## 🎯 Project Objective

The goal of FocusFlow is to combine multiple everyday productivity tools into one intuitive application while exploring responsive web development, JavaScript functionality, browser storage, interactive animations, and modern UI design.
